Hearth — a household budget site that works offline: a live dashboard for a family of four on $5,200 a month, a 50/30/20 budget planner with sliders and presets, an expense tracker with per-category warnings (saved in localStorage), savings goals with progress, and a plain-English guide with a worked example. Plain HTML, CSS and JavaScript; no build step, no network requests.
## Run it
```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
